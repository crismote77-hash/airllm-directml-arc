## CODE REVIEW: AirLLM DirectML patchset for Intel Arc GPU

Review the complete patchset applied on AirLLM v3.0.1 (lyogavin/airllm main). 
Goal: add Intel Arc GPU support via torch-directml while preserving AirLLM's layer-by-layer streaming superpower.

### SCOPE
4 files, +148/-9 lines. All changes are minimal, backward-compatible with CUDA path.

### FILES CHANGED

**1. air_llm/airllm/device_utils.py** (NEW, 122 lines)
Device abstraction module with:
- get_device_type(device) -> normalizes "cuda"|"directml"|"mps"|"cpu"
- is_cuda_device / is_directml_device / can_pin_memory / supports_bitsandbytes
- empty_cache(device) — device-agnostic cache clearing (CUDA + MPS + DirectML passthrough)
- get_free_memory_bytes(device) — returns -1 for non-CUDA
- is_directml_available / get_directml_device
- Guarded torch.mps access (hasattr(torch, "mps") && hasattr(torch.mps, "empty_cache"))

**2. air_llm/airllm/utils.py** (+19/-8 lines)
- clean_memory(): now uses device_utils.empty_cache() for CUDA and MPS, with double-hasattr guard
- find_or_create_local_splitted_path(): added isdir() guard + single-file model detection (model.safetensors / pytorch_model.bin without index.json)

**3. air_llm/airllm/airllm_base.py** (+2/-1 lines)
- Import can_pin_memory from device_utils
- Line 272: replaced torch.cuda.is_available() with can_pin_memory(self.running_device)

**4. air_llm/setup.py** (+4 lines)
- extras_require: {'compression': ['bitsandbytes'], 'directml': ['torch-directml']}
